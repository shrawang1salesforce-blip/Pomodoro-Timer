# Little by little

A small Pomodoro timer that runs in your browser. No install or account needed.

Open `index.html` to get started. Focus and break lengths can be changed in the
settings panel; the timer follows those lengths the next time it is reset.

Start a timer to begin, pause it whenever you need, or reset to the full length.
When a focus session ends, the timer switches to a break and adds one to
today's count. It switches back to focus when the break ends. If you allow
browser notifications, you'll get a note when either timer is done.

Timer lengths and today's completed-session count are saved in this browser.
